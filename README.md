# Backend 学习文档

本仓库是一套后端开发入门文档，面向会写基本 Python 程序、但没有做过后端的读者。内容以 Python 3.12、FastAPI 与 PostgreSQL 为主线：从一次 HTTP 请求出发，说明服务端如何接收请求、处理并发、读写数据库，最后完成一个可运行、可测试、可部署的图书借阅服务。

阅读不要求事先学过网络或数据库。每一章先讲清机制与边界，再给出可以直接运行的例子；示例代码与输出均经过实跑核对。第一次阅读从 [01 后端开发全景](01%20后端开发全景.md) 开始。

---

## 适合谁读

- 会 Python 的变量、函数、循环与异常处理，能使用命令行运行脚本；
- 没有后端经验，或只写过单独运行的程序；
- 不需要前端、网络或数据库基础；
- 不要求类型标注、异步编程或 Web 框架经验，相关概念在用到之前会先说明。

如果还不熟悉 Python 的类、异常与模块，先补这部分语言基础。本仓库不重复语言语法，示例中出现的语言特性会在使用前说明。

---

## 读完之后

- 说明一次请求从浏览器发出到数据库返回所经过的环节，以及每一环失败时的表现；
- 用 FastAPI 写出带参数校验、错误处理与分层结构的 HTTP 服务；
- 用 SQL 与 SQLAlchemy 完成增删改查、事务与并发控制；
- 解释连接池、索引、隔离级别、ORM 会话等机制的作用与取舍；
- 为服务编写测试、迁移脚本与启动配置，并把它部署起来。

---

## 阅读路线

章节按依赖关系排列，建议从 01 顺序读到 13。前三章先让服务跑起来，之后补网络与数据库机制，最后收束到工程实践；每一阶段都以前一阶段为基础。

| 阶段 | 章节 | 解决什么 |
|---|---|---|
| 先跑起来 | 01–03 | 看清请求链路，写出第一个带校验的接口 |
| 网络 | 04–06 | 理解 TCP、并发模型与 HTTP 客户端 |
| 数据 | 07–10 | 理解 SQL、事务、索引、连接池与 ORM |
| 工程 | 11–13 | 分层、认证、部署与完整项目 |

时间有限时，可以先读 01–03，做出一个能访问的接口，再回头补 04–10 的机制。跳过网络与数据库直接使用框架，遇到超时、重复写入或查询变慢时，将难以判断问题出在哪一层。

## 章节目录

目录中带链接的章节已经发布，其余章节按顺序补充。

### 第一部分：先跑起来

- 01丨[**后端开发全景**](01%20后端开发全景.md) —— 一次请求从浏览器到数据库的完整链路、服务端承担的职责、技术栈的分层与本书的阅读路线。
- 02丨**HTTP 与 API 设计** —— 请求方法、状态码、首部、JSON、REST 风格、幂等、分页与错误响应。
- 03丨**第一个 FastAPI 服务** —— 创建工程、定义路由、接收参数、返回响应，并用 OpenAPI 页面调试接口。

### 第二部分：网络

- 04丨**TCP、Socket 与消息边界** —— TCP 连接的生命周期、阻塞与超时、字节流与消息分帧。
- 05丨**并发模型：线程、进程与 asyncio** —— GIL、线程与进程、事件循环、取消、背压，以及阻塞调用进入事件循环的后果。
- 06丨**HTTP 客户端与外部服务** —— httpx 的同步与异步用法、超时、重试、连接复用、TLS 与代理。

### 第三部分：数据

- 07丨**关系模型与 SQL 应用** —— 表、键、约束、连接、`NULL` 语义与查询结果的读取。
- 08丨**事务、隔离级别与并发控制** —— ACID、并发异常、MVCC、锁、重试与幂等写入。
- 09丨**索引、执行计划与查询优化** —— B-tree、选择性、覆盖索引、`EXPLAIN` 与 N+1 查询。
- 10丨**连接池、SQLAlchemy 与 ORM** —— Engine、Session、身份映射、工作单元与迁移。

### 第四部分：工程与项目

- 11丨**FastAPI 分层与事务边界** —— 依赖注入、路由/服务/仓储分层、会话生命周期与提交回滚时机。
- 12丨**认证、配置、日志与部署** —— 鉴权方式、配置管理、结构化日志、健康检查与容器部署。
- 13丨**项目实战：图书借阅 API** —— 综合运用网络、事务、并发、测试与迁移，完成一个可运行的服务。

## 示例与工程

正文中的示例以片段为主，省略与当前概念无关的导入、启动代码与重复的异常处理；省略之处会用文字交代，必要时给出完整文件。示例的输出单独放在输出框中，展示实际运行结果。

第 13 章的完整实现将放在 `assets/projects/library-api/`，包含启动说明、迁移脚本与测试，可作为完成练习后的对照。

---

## 运行环境

示例基于 Python 3.12、FastAPI 0.115、Pydantic 2、SQLAlchemy 2、Alembic 与 PostgreSQL 16。第 03 章从创建工程开始，会给出依赖安装与启动命令；数据库相关章节使用 Docker 启动 PostgreSQL，避免依赖本机安装。

版本变化可能改变行为。示例以文中注明的版本为准，升级依赖后应重新运行示例核对输出。
