# Backend 学习文档

本仓库是一套 **后端开发入门文档**，面向会写基本程序、但没有做过后端的读者。主线只有一条：从一次 HTTP 请求出发，理解服务端如何接收请求、处理并发、读写数据库，最后用 **Python + FastAPI + PostgreSQL** 做成一个可运行、可测试、可部署的小服务。

文档不以罗列框架 API 为目标。每一章先讲清机制与边界，再给出能实际运行的例子；代码与输出都经过实跑核对。

---

## 读者与目标

读者应当能读懂变量、函数、循环与基本的命令行操作。不要求 Java、C/C++ 或前端基础，也不要求事先学过网络与数据库。

读完之后应当能够：

- 说明一次请求从浏览器发出到数据库返回所经过的环节；
- 用 FastAPI 写出带参数校验、错误处理与分层结构的 HTTP 服务；
- 用 SQL 与 SQLAlchemy 完成常见的增删改查、事务与并发控制；
- 解释连接池、索引、隔离级别、ORM 会话等机制的作用与取舍；
- 为一个服务编写测试、迁移脚本与启动配置，并把它部署起来。

## 写作约定

沿用 `Java` 文档仓库的硬性规范，其中与读者关系最直接的部分如下：

- 唯一判断标准是读者读完能否复述发生了什么。
- 每个示例代码框前后各有一段文字：框前交代数据与问题，框后逐行说明代码与输出。
- 代码中出现的 API 先说明后使用；方法各占一个小标题，先给契约句，再给签名，再展开参数、返回、失败行为与边界。
- 示例代码与输出必须实际运行核对，错误变体同样要跑。
- 与 Java 的对照写成引用块 `> 🆚 **与 Java 的对照**`，只在确有帮助时出现。
- 引号统一使用直角引号「」。
